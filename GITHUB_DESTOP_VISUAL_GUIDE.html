第一步：下载并安装 GitHub Desktop

1

打开浏览器，访问：https://desktop.github.com/

第六步：下载 APK

10

11
下载 APK

构建成功后，下载 APK 文件：

  1. 在 Actions 标签，点击刚刚完成的工作流
  2. 进入工作流详情页，滚动到页面底部
  3. 找到 Artifacts 部分
  4. 点击 gift-ledger-app-debug
  5. 浏览器自动下载 ZIP 文件

❓ 常见问题

❓
构建失败怎么办？

如果 GitHub Actions 构建失败：

  1. 在 Actions 标签，点击失败的工作流
  2. 点击 build 任务
  3. 查看红色的错误日志
  4. 常见问题：
    • Gradle 同步失败：重新运行工作流
    • 依赖下载失败：重新运行工作流
    • SDK 版本错误：检查 build.gradle 文件
  5. 重新运行工作流：
    • 在工作流详情页，点击右上角 Re-run all jobs
❓
找不到 APK 下载链接？

如果构建成功但找不到 APK：

  1. 确保在 Actions 标签
  2. 点击成功的工作流
  3. 滚动到页面 最底部
  4. 找到 Artifacts 部分（可能在右侧）
  5. 如果看不到，尝试刷新页面
